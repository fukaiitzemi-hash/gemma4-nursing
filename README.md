#  Gemma 4: Nursing Assessment Support AI

A professional clinical reasoning copilot that transforms raw patient data into structured nursing diagnoses right at the bedside.

---

##  Key Features
*   **Voice Input Ready:** Fully compatible with smartphone built-in microphone/speech-to-text dictation for fast, hands-free operation in the field.
*   **Structured Markdown Output:** Instantly generates clinical assessments in beautiful Markdown format (including full **SOAP** charting and educational rationales).

---

##  How to Use (Quick Start)

### 1. Backend Setup (Cloud Compute)
1. Launch the notebook on **Kaggle** (or any cloud environment equipped with a high-performance GPU).
2. Execute the server code utilizing **4-bit quantization** to initialize the Gemma 4 engine.
3. Copy the secure public URL (`https://...gradio.live`) instantly generated by **Gradio**.

### 2. Frontend Access (Mobile Client)
1. Open the copied URL in any standard browser (Safari, Chrome, etc.) on your **smartphone**.
2. **Zero-install required:** Paste or dictate your patient logs directly into the text box and select your desired output mode to get real-time clinical reasoning support!
